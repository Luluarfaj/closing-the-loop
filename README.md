# Derived data for "Closing the Loop"

Alarfaj, L., Rawat, N., Branch-Elliman, W. and Ertem, M. Z.

Twenty derived datasets, all state-level aggregates computed from public sources. No data were
collected from human participants and nothing here identifies an individual. The original sources,
their identifiers and the exact queries are given in the Data availability statement of the paper.

The simulation is not represented here. It reads no input file of any kind; its inputs are the
parameter values given in the Methods, and its results are regenerated by running
`two_sigma_report.py`.

## Reproducing them

```bash
pip install -r requirements.txt
python3 build_respiratory.py   # linkage
python3 compute_d.py           # the divergence
python3 decision_rule.py       # the 408 decisions
python3 two_sigma_report.py    # every simulation number
python3 stats_intervals.py     # every reported coefficient and interval
python3 numerical_checks.py    # the numerical checks on the simulation
```

Two sources are not fixed in time. The Delphi COVIDcast series is revised after first publication,
so pass `as_of=20260715` to reproduce our extract exactly. Google Trends returns a relative,
resampled index that can shift between pulls; the copy we used is `flu_trends_by_state.csv`.
